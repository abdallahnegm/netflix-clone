# 🎬 Netflix Clone

A modern Netflix-inspired movie streaming platform built with React, Vite, Tailwind CSS, and the TMDB API.

The project provides a responsive movie and TV browsing experience with search, authentication, favorites, trailers, movie details, multilingual support, and more.

## 🚀 Live Demo

https://netflix-clone-ivory-sigma.vercel.app/

## 📂 GitHub Repository

https://github.com/abdallahnegm/netflix-clone

---

## ✨ Features

- 🎬 Browse trending, popular, top-rated, and upcoming movies
- 📺 Browse TV shows and series
- 🔎 Search for movies and TV shows
- 🎥 Movie and TV show details pages
- ▶️ Watch available movie trailers
- ❤️ Add and remove movies and TV shows from My List
- 🔐 User registration and login
- 🛡️ Protected routes for authenticated users
- 🌐 English and Arabic language support
- ↔️ RTL support for Arabic
- 📱 Fully responsive design
- ⏳ Loading skeletons
- ⚠️ API error handling
- 🎞️ Responsive movie sliders using Swiper
- 🔝 Top 10 movies section
- 🔄 Dynamic content fetched from TMDB API
- 🚀 Deployed with Vercel

🌍 Language Support

The application supports:

🇬🇧 English
🇪🇬 Arabic

Arabic mode automatically switches the application direction to RTL.

The selected language is stored in localStorage.

TMDB API

This project uses the TMDB API to fetch movie and TV show data.

You can get your own API key from:

https://www.themoviedb.org/

Make sure your API key is stored in the .env file and is not committed to GitHub.

🔐 Authentication

The project includes a simple client-side authentication system with:

User registration
User login
Logout
Protected routes
User-specific My List

Authentication data is stored locally using localStorage.

This authentication system is implemented for frontend practice and demonstration purposes.

📱 Responsive Design

The application is designed to work across:

Desktop
Laptop
Tablet
Mobile

The navigation and movie sliders adapt to different screen sizes.
